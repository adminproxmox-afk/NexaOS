# NexaOS 0.3

NexaOS запускает 32-битный Linux 6.12 и BusyBox внутри v86/WebAssembly. Профиль NexaOS открывает гостевую консоль COM1. Профиль NexaDesktop предназначен для первого графического сеанса X.Org с гостевым xterm.

## Запуск

В **Windows с WSL2 Ubuntu 24.04** выполните команды из папки проекта в PowerShell.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
wsl -d Ubuntu-24.04 -- bash scripts/build-linux.sh
py -3 -m http.server 8000 --bind 127.0.0.1
```

Первый запуск сборки требует пакетов Ubuntu из [инструкции по Buildroot](docs/build.md). Имя дистрибутива можно проверить командой `wsl -l -v`. Если лаунчер `py` недоступен, используйте `python`.

В **Linux** установите [зависимости сборки](docs/build.md) и выполните следующие команды.

```bash
bash scripts/setup.sh
bash scripts/build-linux.sh
bash scripts/run-dev.sh
```

Откройте [localhost:8000](http://127.0.0.1:8000/), выберите **NexaOS 0.3** и нажмите **Включить**. После `nexaos login:` щёлкните внутри терминала и введите `user`. Этот локальный пользователь входит без пароля. `Ctrl+]` выводит фокус из консоли к элементам управления.

```sh
uname -a
pwd
ls /
mkdir -p ~/probe
cat /etc/os-release
ps
mount
```

Профиль **Демонстрационный Linux ISO** доступен сразу после `setup`, без сборки NexaOS. Профиль **Свой образ · VGA** загружает совместимые `assets/bzImage` и `assets/rootfs.cpio.gz` по схеме загрузчика 0.1. Он показывает состояние эмуляции, поскольку критерий готовности произвольного образа заранее неизвестен. В режиме VGA фокус возвращается к элементам управления по F6.

## Постоянные файлы и NexaDesktop

Оба профиля NexaOS подключают один ext4-диск на 64 МиБ к `/home/user`. **Выключить** и **Перезагрузить** сначала сохраняют диск, затем останавливают VM. После сообщения **Диск сохранён** следующий запуск откроет записанные файлы. Изменения в `/tmp` и в остальных каталогах initramfs сбрасываются.

Диск хранится в IndexedDB для текущего профиля браузера и адреса сайта. Для продолжения используйте тот же адрес, включая порт. Закрытие вкладки или сбой до штатного выключения оставляют последнюю сохранённую версию. Если запись в IndexedDB не удалась, можно повторить выключение или явно остановить VM с предыдущей версией диска.

Для профиля **NexaDesktop · X.Org** нужен образ после завершения сборки графических пакетов. Переключатель **Открыть COM1** показывает гостевую консоль и журналы в `/var/log/`. **Открыть VGA** возвращает графический экран, F6 передаёт фокус элементам управления.

## Исходники

| Путь | Содержимое |
| --- | --- |
| `index.html`, `style.css`, `app.js`, `web/` | Диспетчер загрузки, IndexedDB и логотип |
| `linux/configs/nexaos_defconfig` | Конфигурация Buildroot для i686 |
| `linux/board/nexaos/` | Конфигурация ядра, контрольная сумма и учётная запись |
| `linux/rootfs-overlay/` | Init, управление ext4 через COM2, X.Org и гостевой сеанс |
| `scripts/` | Установка зависимостей браузера, сборка, HTTP-сервер |
| `assets/` | Локальные зависимости и образы, подготовленные скриптами |
| `tests/` | Сквозные проверки загрузчика, сохранения ext4 и графического сеанса |
| `docs/` | [Архитектура](docs/architecture.md), [сборка и проверка](docs/build.md), [дальнейшие этапы](docs/roadmap.md) |
