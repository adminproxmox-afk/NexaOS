# NexaOS 0.2

NexaOS запускает 32-битный Linux 6.12 и BusyBox внутри v86/WebAssembly. Диспетчер загрузки работает в браузере, а команды выполняются в гостевой системе через последовательный порт COM1.

## Запуск

В **Windows с WSL2 Ubuntu 24.04** выполните команды из папки проекта в PowerShell.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
wsl -d Ubuntu-24.04 -- bash scripts/build-linux.sh
py -3 -m http.server 8000 --bind 127.0.0.1
```

Первый запуск сборки требует пакетов Ubuntu из [инструкции по Buildroot](docs/build.md). Имя дистрибутива можно проверить командой `wsl -l -v`. Если лаунчер `py` недоступен, используйте `python`.

В **Linux** установите [зависимости сборки](docs/build.md) и выполните следующие команды.

```bash
bash scripts/setup.sh
bash scripts/build-linux.sh
bash scripts/run-dev.sh
```

Откройте [localhost:8000](http://127.0.0.1:8000/), выберите **NexaOS 0.2** и нажмите **Включить**. После `nexaos login:` щёлкните внутри терминала и введите `user`. Этот локальный пользователь входит без пароля. `Ctrl+]` выводит фокус из консоли к элементам управления.

```sh
uname -a
pwd
ls /
mkdir -p ~/probe
cat /etc/os-release
ps
mount
```

Профиль **Демонстрационный Linux ISO** доступен сразу после `setup`, без сборки NexaOS. Профиль **Свой образ · VGA** загружает совместимые `assets/bzImage` и `assets/rootfs.cpio.gz` по схеме загрузчика 0.1. Он показывает состояние эмуляции, поскольку критерий готовности произвольного образа заранее неизвестен. В режиме VGA фокус возвращается к элементам управления по F6.

**Перезагрузить** выполняет холодный запуск с тем же образом и объёмом памяти. **Выключить** останавливает v86 и освобождает ресурсы. Файлы гостя и другие изменения в RAM сбрасываются в обоих случаях.

## Исходники

| Путь | Содержимое |
| --- | --- |
| `index.html`, `style.css`, `app.js`, `web/nexa.svg` | Диспетчер загрузки и логотип |
| `linux/configs/nexaos_defconfig` | Конфигурация Buildroot для i686 |
| `linux/board/nexaos/` | Конфигурация ядра, контрольная сумма и учётная запись |
| `linux/rootfs-overlay/` | NexaOS init, конфигурация BusyBox init, баннер и идентификатор релиза |
| `scripts/` | Установка зависимостей браузера, сборка, HTTP-сервер |
| `assets/` | Локальные зависимости и образы, подготовленные скриптами |
| `tests/browser-smoke.js` | Проверка браузерного загрузчика и команд внутри гостя |
| `docs/` | [Архитектура](docs/architecture.md), [сборка и проверка](docs/build.md), [план 0.3](docs/roadmap.md) |

Гостевая сессия работает в RAM. В NexaOS 0.2 доступна консоль, сетевой мост отсутствует. Поддержка ext4 с постоянным хранилищем и гостевой графический сеанс описаны в плане 0.3.
